Method 2 Standard

Android Studio / CLI Build

Open the unzipped directory in Android Studio (Giraffe, Hedgehog, Iguana or newer) or run the single Gradle command from your terminal:

./gradlew assembleDebug
Outputs: app/build/outputs/apk/debug/app-debug.apk
Install directly via ADB: adb install -r app-debug.apk
Method 3 On Android

Compile Directly in Termux

Build the APK without a PC using Termux on your phone with OpenJDK 17:

pkg install openjdk-17 git
unzip ChronoSync-BLE-Android.zip
cd ChronoSync-BLE-Android
chmod +x gradlew && ./gradlew assembleDebug
Ready to install on target phone with full MediaProjection & BLE permissions.
